如何配置 GLM Token

方式 1: 访客模式（当前默认）

无需配置，系统自动获取临时访客 Token。适合测试和低频使用。

方式 2: 用户模式（推荐）

在 .env 文件中配置： 

# 单个 Token
GLM_REFRESH_TOKEN=your_refresh_token_here

# 或多个 Token（逗号分隔，自动负载均衡）
GLM_REFRESH_TOKENS=token1,token2,token3

获取 Refresh Token

  1. 登录 https://chatglm.cn
  2. 打开浏览器开发者工具（F12）→ Network
  3. 在请求中找到包含 Authorization 头的请求
  4. 复制 Bearer 后面的 Token 到 .env 文件
